# Bump｜桌面演示启动卡

**在 Windows 64 位电脑上，双击本文件旁边的 `Start-Bump.cmd`；macOS / Linux 在 `group9` 目录执行 `./run.sh setup && ./run.sh demo`。** 首次启动会创建项目内 `.venv` 并在演示目录生成账号、证书和数据库。已有的演示运行库会继续使用。

1. 保留黑色服务窗口。网页会自动打开；若未打开，将窗口内显示的 `http://127.0.0.1:端口` 地址复制到浏览器。初始通常是 **8765**，首次如有冲突会自动改用空闲端口。不对外发布。
2. 用记事本打开启动窗口指出的 **`.runtime\credentials.txt`**，找到 **alice** 行，只复制冒号和空格后面的完整口令。若口令以短横线或下划线结尾，也要复制。
3. 点击网页的**模拟发现**按钮（若按钮文案为“一键模拟”或“模拟摇动”，含义相同）；它会用两枚软件挂件快进 60 秒发现窗口。看到 `B00002` 的记录、模拟来源和应用确认后，由 Alice 发出联系邀请。
4. **退出后登录 bob**。同意前，资料仍隐藏；同意后，双方可见的只是虚构演示资料。可撤销联系，资料会再次隐藏。**charlie** 是无关第三人，不会看到 Alice/Bob 的记录或邀请。
5. 已经从同一副本启动时，再次双击同一入口即可打开原网页并继续查看本地历史。完成后在服务窗口按 **Ctrl+C** 停止服务。只关闭浏览器标签页时，服务会继续运行。

### 什么是真实的，什么是模拟的？

- 网页、登录/授权、本机 MQTT/TLS、SQLite 持久化和应用 ACK 实际运行。
- 摇动、第二枚挂件、RSSI/采样和双机发现是**模拟输入**，并非实物 BLE 距离、在线或板端摇动证据。60 秒是被快进的发现窗口，不需要真的等待一分钟。
- 页面中的最后收件时间是本机服务器落库的时间，不是设备心跳。软件不能证明实物当前在线；页面演示无需红外。
- 若收到失败提示，先刷新时间线查看是否已写入部分记录，再决定是否重试。重复点击不会绕过联系申请或同意；重新运行一次正常场景则会产生新的模拟观察。

### 文件与故障

- 汇总包根的 `.local-tools\` 保存共享运行环境，本演示目录的 `.runtime\` 含本机密码、证书及数据库。分发使用项目提供的 ZIP，离线依赖见包根 `09_离线运行依赖\python-win-x64.zip`。
- 若运行窗口显示端口被占用，检查是否已打开了本项目的服务窗口。用原窗口的地址，或在原窗口按 Ctrl+C 再启动；无需关闭 Wi-Fi、关闭防火墙或改系统设置。
- 仅验证离线环境而不创建账号、数据库或打开浏览器：在本目录的 PowerShell 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-LocalWeb.ps1 -SelfCheck`。这里的 `Bypass` 只限这一进程，不改系统执行策略。启动但不自动打开浏览器可传 `-NoBrowser`。
