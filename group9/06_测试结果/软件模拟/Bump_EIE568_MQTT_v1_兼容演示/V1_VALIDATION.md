# MQTT v1 兼容版｜验证记录

**2026-11-18，Windows x64，包内 Python 3.12.14；所有演示输入为软件模拟。** 使用独立临时运行目录/端口，没有读取或迁移旧桌面演示的账号、密码、证书或数据库。

| 验证层 | 已观察到的结果 |
|---|---|
| 附件来源 | 原 ZIP（22,287 字节）的 CRC、路径和 UTF‑8 文档检查通过。3 个 Markdown，没有固件或可执行文件。 |
| 离线启动环境 | 重新从包内 ZIP 解压后自检成功，使用项目内 Python、FastAPI 0.161.1、SQLite 3.53.1、aMQTT 0.11.4。 |
| v1 报文与数据 | 同次 pytest：**109 passed**（86 报文 + 23 存储）。包括 UTF‑8 2 KiB、单批最多 8 条、ID/主题/身份、NTP/uptime、幂等与事务回滚、24h 身份歧义、900 秒互遇、8h 展示窗口、状态新鲜度及隐私。 |
| v1 浏览器 API | **5 passed**。涵盖会话和 CSRF、禁止任意输入、公共健康不泄露身份、未确认时返回失败、不交叉隐藏。 |
| v1 MQTT 专项 | **6 passed，7.10 秒**。冻结版将未处理线程警告升级为错误复测，先前发现的关停警告已修正，本次 0 个此类警告。通过真正的回环 TLS 连接观察到每次 online×2、encounters×2、offline×2，验证真实持久化与权限，而非把 PUBACK 当入库。 |
| 网页行为 | Node 实际执行新 8 组和旧 3 组；Python 测试入口合跑 **2 passed**。HTML/JS 静态检查通过，未在真实浏览器中进行视觉验收。 |
| 旧功能回归 | 单独 38 项全部通过：其中 36 项为既有 API/存储，2 项是上述新 HTTP 组中的测试，**不可重复相加**。 |
| 端到端 | **7 组真实 HTTP 联调通过**：启动后 broker/数据库就绪、拒绝匿名、身份约束、两端软件 MQTT/TLS 入库和互遇、第二轮聚合、本人隐藏、旧轨的发现→邀请→同意→撤销。客户端通过实际 loopback HTTP 访问；没有使用运行中用户的浏览器会话。 |

各项是分层与交叉验证，不相加成“全仓通过数”。未把生产部署、实体挂件、完整 Bearer REST、持久 MQTT 会话/LWT、无线功耗与距离、C++/板端编译或浏览器视觉检查计作本次实测。综合运行被环境阻止，未放行未经请求的外联。

复现重点请运行根目录 `Test-V1.ps1`；端到端的逐项摘要在本目录 `v1-http-smoke.json`。
