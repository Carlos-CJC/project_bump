# 硬件接线说明（Arduino Nano RP2040 Connect）

## 元件

- 四脚轻触按钮 × 2：**白色按钮**、**蓝色按钮**
- 三引脚 IR 发射模块 × 1（丝印可能为 `S / + / -` 或 `DAT / VCC / GND`，以模块丝印为准）

## 引脚分配

| 元件 | 连接到 |
|---|---|
| 白色按钮（按钮 1）一脚 | GND |
| 白色按钮（按钮 1）对角脚 | **D2** |
| 蓝色按钮（按钮 2）一脚 | GND |
| 蓝色按钮（按钮 2）对角脚 | **D3** |
| IR 模块 S（信号） | **D9** |
| IR 模块 +（电源） | 3V3 |
| IR 模块 -（地） | GND |

按钮另一端共用 Arduino 的 GND。

## 接线图

```
            Arduino Nano RP2040 Connect
        ┌─────────────────────────────┐
 D13 ───┤ ●                         ● ├─── D12
  3V3 ──┤ ●  ← IR 模块 +            ● ├─── D11
 AREF ──┤ ●                         ● ├─── D10
   A0 ──┤ ●                         ● ├─── D9   ← IR 模块 S
   A1 ──┤ ●                         ● ├─── D8
   A2 ──┤ ●                         ● ├─── D7
   A3 ──┤ ●                         ● ├─── D6
   A4 ──┤ ●                         ● ├─── D5
   A5 ──┤ ●                         ● ├─── D4
   A6 ──┤ ●                         ● ├─── D3   ← 蓝色按钮
   A7 ──┤ ●                         ● ├─── D2   ← 白色按钮
   5V ──┤ ●                         ● ├─── GND
  RST ──┤ ●                         ● ├─── RST
  GND ──┤ ●  ← 按钮公共地           ● ├─── D0/RX
  VIN ──┤ ●                         ● ├─── D1/TX
        └─────────────────────────────┘
```

四脚轻触开关（同一侧的两个脚内部相通，按下时左右两组导通，建议接对角脚）：

```
   ┌─────────┐
   │ ●     ● │   左/右同侧两脚各自相通
   │    ▄    │   按下 → 左右导通
   │ ●     ● │
   └─────────┘
     │     │
    GND   D2 (白色) / D3 (蓝色)
```

IR 发射模块：

```
   S  ──→ D9
   +  ──→ 3V3
   -  ──→ GND
```

## 注意事项

- RP2040 为 **3.3V 逻辑**，禁止把 5V 直接接入 GPIO。
- 按钮使用 `pinMode(pin, INPUT_PULLUP)`，无需外接上拉电阻；**按下读到 `LOW`**，松开读到 `HIGH`（注意逻辑反转）。
- 按钮建议做软件消抖（20–50 ms）。
- IR 模块 S 为输入脚，只发不收；若遥控距离不足，可将模块 `+` 改接 5V（S 仍由 3.3V GPIO 驱动，安全），或加 NPN 三极管放大电流。
- IR 发送使用 `IRremote` 库（支持 RP2040），发送脚定义为 9。
