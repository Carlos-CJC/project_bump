# Bump 智能社交挂件 · EIE568 Group 9

Bump 的目标是让两位佩戴者记录一次相遇，并各自决定是否分享资料。使用两枚软件挂件演示“发现相遇 → 发出邀请 → 同意分享”，可在 Windows 64 位电脑上双击[兼容版启动器](../../01_前端源码/Bump_EIE568_MQTT_v1_兼容演示/Start-Bump.cmd)。[桌面演示启动卡](../../01_前端源码/Bump_EIE568_MQTT_v1_兼容演示/LOCAL_WEB_GUIDE.md)
