# 硬件接线说明（Arduino Nano RP2040 Connect）

## 元件

- 四脚轻触按钮 × 2：**白色按钮**、**蓝色按钮**
- 三引脚 IR 发射模块 × 1（丝印可能为 `S / + / -` 或 `DAT / VCC / GND`，以模块丝印为准）
- 三引脚 IR 接收模块 × 1（常见型号 HX1838 / VS1838B，带金属屏蔽罩；丝印可能为 `OUT / VCC / GND` 或 `DAT / + / -`，**引脚顺序各厂家不同，务必以丝印为准**）

## 引脚分配

| 元件 | 连接到 |
|---|---|
| 白色按钮（按钮 1）一脚 | GND |
| 白色按钮（按钮 1）对角脚 | **D2** |
| 蓝色按钮（按钮 2）一脚 | GND |
| 蓝色按钮（按钮 2）对角脚 | **D3** |
| IR 发射模块 S（信号） | **D9** |
| IR 发射模块 +（电源） | 3V3 |
| IR 发射模块 -（地） | GND |
| IR 接收模块 OUT（信号） | **D4** |
| IR 接收模块 VCC（电源） | 3V3 |
| IR 接收模块 GND（地） | GND |

按钮另一端共用 Arduino 的 GND；发射模块与接收模块的电源、地也共用 3V3 和 GND。接收信号脚选 D4 只是建议，D4–D8、D10–D13 等空闲脚都可改（代码里同步改即可）。

## 接线图

```
            Arduino Nano RP2040 Connect
        ┌─────────────────────────────┐
 D13 ───┤ ●                         ● ├─── D12
  3V3 ──┤ ●  ← IR 模块 +            ● ├─── D11
 AREF ──┤ ●                         ● ├─── D10
   A0 ──┤ ●                         ● ├─── D9   ← IR 模块 S
   A1 ──┤ ●                         ● ├─── D8
   A2 ──┤ ●                         ● ├─── D7
   A3 ──┤ ●                         ● ├─── D6
   A4 ──┤ ●                         ● ├─── D5
   A5 ──┤ ●                         ● ├─── D4   ← IR 接收 OUT
   A6 ──┤ ●                         ● ├─── D3   ← 蓝色按钮
   A7 ──┤ ●                         ● ├─── D2   ← 白色按钮
   5V ──┤ ●                         ● ├─── GND
  RST ──┤ ●                         ● ├─── RST
  GND ──┤ ●  ← 按钮公共地           ● ├─── D0/RX
  VIN ──┤ ●                         ● ├─── D1/TX
        └─────────────────────────────┘
```

四脚轻触开关（同一侧的两个脚内部相通，按下时左右两组导通，建议接对角脚）：

```
   ┌─────────┐
   │ ●     ● │   左/右同侧两脚各自相通
   │    ▄    │   按下 → 左右导通
   │ ●     ● │
   └─────────┘
     │     │
    GND   D2 (白色) / D3 (蓝色)
```

IR 发射模块：

```
   S  ──→ D9
   +  ──→ 3V3
   -  ──→ GND
```

IR 接收模块（三引脚，OUT 为信号输出）：

```
   OUT ──→ D4
   VCC ──→ 3V3
   GND ──→ GND
```

> ⚠️ 接收模块的引脚顺序各厂家不同（常见 `OUT / GND / VCC`，也有 `VCC / GND / OUT`）。接线前务必核对模块丝印，**VCC 与 GND 接反会烧毁模块**。
>
> 若丝印是 `S / + / -`：`S → D4`、`+ → 3V3`、`- → GND`。接收头是黑色带屏蔽罩的元件，别和透明的发射 LED 弄混。

## 注意事项

- RP2040 为 **3.3V 逻辑**，禁止把 5V 直接接入 GPIO。
- 按钮使用 `pinMode(pin, INPUT_PULLUP)`，无需外接上拉电阻；**按下读到 `LOW`**，松开读到 `HIGH`（注意逻辑反转）。
- 按钮建议做软件消抖（20–50 ms）。
- IR 发射模块的 S 是由 GPIO 驱动的输入脚（只发不收）；若发射距离不足，可将**发射模块** `+` 改接 5V（S 仍由 3.3V GPIO 驱动，安全），或加 NPN 三极管放大电流。
- IR 接收模块必须用 **3V3** 供电，不要接 5V：OUT 的高电平跟随 VCC，接 5V 时可能把 5V 灌进 GPIO。OUT 是解调后的数字信号，空闲为 `HIGH`，收到 38 kHz 红外时输出 `LOW` 脉冲；代码用 `INPUT` 或 `INPUT_PULLUP` 读取均可（模块自带上拉）。
- 接收模块只响应 **38 kHz** 载波，用普通 38 kHz 红外遥控器测试最方便。若接收不稳定，在模块 VCC–GND 之间就近加 100 nF 去耦电容，并避免阳光或日光灯直射接收头。
- 发射（D9）与接收（D4）可同时工作，但不要让发射头紧贴接收头，否则容易饱和、误码。
- 代码使用 `IRremote` 库（支持 RP2040）：发送脚为 9；接收初始化为 `IRrecv IrReceiver(4);` / `IrReceiver.begin(4);`（IRremote 4.x 写法）。
